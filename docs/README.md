# 点餐系统小程序端

本项目是《跨端应用开发》课程实验作业，使用 uni-app + Vue + Vuex 完成微信小程序端点餐流程。项目没有接入真实后端、真实微信支付和手机号授权，相关能力统一用 mock 数据降级，方便在 HBuilderX 和微信开发者工具中演示、截图和写实验报告。

## 技术栈

- uni-app
- Vue
- Vuex
- pages.json 路由配置
- utils/request.js 统一请求封装
- utils/mock.js 提供课程演示数据

## 启动方式

1. 在当前目录安装依赖：

```bash
npm install
```

2. 构建微信小程序端：

```bash
npm run build:mp-weixin
```

3. 使用微信开发者工具导入：

```text
D:\跨端应用开发\dist\build\mp-weixin
```

也可以直接用 HBuilderX 打开 `D:\跨端应用开发`，选择“运行到小程序模拟器 / 微信开发者工具”。

## 演示流程

1. 首页查看定位、banner、热门搜索和附近商家。
2. 进入搜索页，点击热门关键词或输入关键词搜索。
3. 进入点餐页，切换分类，查看菜品详情，加入购物车。
4. 打开商家信息，查看电话、营业时间和模拟地图。
5. 登录页模拟微信登录。
6. 购物车进入提交订单页，模拟支付成功。
7. 在我的订单中查看已付款订单和订单详情。
8. 在个人中心修改资料、绑定手机号、申请退款。

## mock 说明

- 微信登录：调用 `uni.login`，无法获取真实 code 时使用 `mock_code`。
- 手机号绑定：使用表单和 mock 验证码 `123456`。
- 支付：提交订单后直接生成已付款订单，保证课程演示流程连贯。
- 商家、菜品、搜索、订单：由 `utils/mock.js` 返回默认数据。
- 地图：展示模拟地图和经纬度，不依赖真实地图权限。

# 小程序上传与发布流程记录

本项目是课程实验项目，实际发布时需要使用真实微信小程序 AppID。当前仓库中的 `manifest.json` 没有填写真实 AppID，演示时可以用测试号或微信开发者工具测试模式导入。

## HBuilderX 上传流程

1. 使用 HBuilderX 打开项目根目录 `D:\跨端应用开发`。
2. 检查 `manifest.json`，在微信小程序配置中填写自己的 AppID。
3. 选择菜单“发行”或“运行”，目标选择“微信小程序”。
4. HBuilderX 会生成微信小程序代码，一般在 `unpackage/dist/build/mp-weixin` 或 CLI 构建目录中。
5. 打开微信开发者工具，导入生成后的小程序目录。
6. 在微信开发者工具中确认页面可以运行，没有明显报错后，点击“上传”。

## 版本管理

1. 上传前先在 git 中提交当前代码，保证版本可追踪。
2. 上传时填写版本号，例如 `1.0.0`。
3. 上传说明可以写“课程实验点餐小程序端，完成首页、点餐、购物车、订单、个人中心等模块”。
4. 如果后面修改页面或修复问题，再提交 git，并上传新的版本号。

## 体验版与体验人员

1. 上传成功后，进入微信公众平台小程序后台。
2. 在“版本管理”中找到刚上传的开发版本。
3. 设置为体验版。
4. 在“成员管理”中添加体验成员微信号。
5. 体验人员扫码后可以在手机上查看小程序效果。

## 提交审核与发布

1. 课程作业一般只需要演示和截图，不一定要正式发布。
2. 如果需要正式发布，在小程序后台提交审核。
3. 填写服务类目、版本说明和测试账号等信息。
4. 审核通过后点击发布。
5. 本课程项目使用 mock 登录、mock 支付和 mock 手机号绑定，不建议作为真实商业小程序发布。

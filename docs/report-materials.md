## 实验一：点餐小程序首页

### 内容及过程记录

本次实验完成了点餐小程序首页。页面顶部显示当前定位地址，中间放置搜索入口和活动推荐 banner，下方展示附近商家列表。商家列表使用了单独的商家卡片组件，卡片中显示店名、评分、月售、起送价、配送费、距离和标签。首页还配置了下拉刷新、上拉加载更多和小程序分享。

首页数据通过 Vuex 的 `home` 模块保存，包括定位信息、热门搜索、最近搜索、banner 和商家列表。接口没有接入真实后端，统一通过 `utils/request.js` 调用 mock 数据。

### 结果与分析

首页可以正常显示默认数据，不会出现空白页。下拉刷新会重新加载首页数据，上拉到底时会显示“已经到底了”。点击搜索入口可以进入搜索页，点击商家卡片可以进入点餐页。

### 用到的知识点

uni-app 页面生命周期、`pages.json` 页面配置、Vuex 状态管理、组件封装、下拉刷新、上拉加载、小程序分享。

### 建议截图页面

首页整体、商家列表、热门搜索和 banner 区域。

### 对应 git commit message

`feat: complete home page experiment`

## 实验二：点餐功能用户模块

### 内容及过程记录

本次实验完成搜索页和点餐页。搜索页包含热门搜索、最近搜索和搜索结果列表，用户可以输入关键词，也可以直接点击热门词。点餐页展示菜品分类、菜品列表和菜品详情弹窗，支持菜品数量增加、减少，并能加入购物车。

菜品列表和菜品详情分别封装为 `goods-list` 和 `goods-detail` 组件。搜索接口和菜品接口分别放在 `api/search/index.js` 和 `api/goods/index.js`，页面数据由 Vuex 的 `search`、`goods` 模块管理。

### 结果与分析

搜索和点餐流程可以跑通。点击商家进入点餐页后，页面会加载该商家的菜品。点击菜品可以查看详情，点击加号可以加入购物车，购物车数量和金额会同步变化。

### 用到的知识点

页面跳转、搜索表单、Vuex 模块拆分、父子组件通信、列表渲染、弹窗交互、购物车状态联动。

### 建议截图页面

搜索页、点餐页、菜品详情弹窗、加入购物车后的效果。

### 对应 git commit message

`feat: complete goods ordering experiment`

## 实验三：点餐商家模块

### 内容及过程记录

本次实验完成商家信息组件和地图页。商家信息中展示店名、评分、地址、电话、营业时间和公告。拨打电话功能优先调用 `uni.makePhoneCall`，如果环境不支持真实拨打，就使用 `uni.showToast` 做模拟提示。地图页展示模拟地图、商家经纬度和地址。

商家详情接口放在 `api/shop/index.js`，状态放在 Vuex 的 `shop` 模块中。

商家信息可以在点餐页中正常显示。点击“拨打电话”可以触发模拟或真实拨号逻辑，点击“查看位置”可以进入地图页。由于课程项目不依赖真实地图权限，所以用 mock 经纬度保证截图和演示稳定。

### 用到的知识点

组件复用、uni-app 原生能力调用、失败降级、路由传参、mock 地图展示。

### 建议截图页面

商家信息区域、地图页经纬度展示。

## 实验四：会员登录模块

### 内容及过程记录

本次实验完成会员登录页面和用户状态管理。页面提供“微信登录模拟”按钮，登录时先尝试调用 `uni.login` 获取 code，如果当前环境无法获取真实 code，则使用 `mock_code`。mock 接口返回 uid、token、openid、昵称和头像，登录成功后保存到 Vuex 和本地 storage。

项目中还实现了 `isLogin` 判断和登录拦截方法。提交订单、个人资料等需要登录的页面会在未登录时跳转到登录页。

### 结果与分析

登录流程可以正常演示。登录后进入个人中心能看到用户昵称和头像，刷新或重新进入页面时也能从本地 storage 恢复登录状态。

### 用到的知识点

`uni.login`、本地缓存、Vuex getters、登录状态判断、页面拦截、mock 登录。

### 建议截图页面

登录页、登录成功后的个人中心。

### 对应 git commit message

`feat: complete member login experiment`

## 实验五：购物车模块

### 内容及过程记录

本次实验完成购物车组件和购物车 Vuex 模块。用户在点餐页点击加号可以把菜品加入购物车，购物车支持增加数量、减少数量、清空购物车、空状态展示，并自动计算总数量和总价。

购物车组件固定在点餐页底部，点击购物车区域可以展开购物车面板，点击“去结算”进入提交订单页。

### 结果与分析

购物车交互比较完整，数量变化后底部总价会实时更新。清空购物车后显示空状态，未选择菜品时点击结算会提示先选择菜品。

### 用到的知识点

Vuex getters、组件事件、固定底部栏、数量步进器、购物车总价计算、空状态处理。

### 建议截图页面

购物车底部栏、购物车展开面板、空购物车状态。

### 对应 git commit message

`feat: complete cart experiment`

## 实验六：订单管理

### 内容及过程记录

本次实验完成提交订单页和支付成功页。提交订单页展示配送地址、商品列表、备注输入、商品总价、配送费和实付款。点击提交订单后生成 mock 订单，并模拟支付成功，然后跳转到支付成功页。

## 实验七：支付管理

### 内容及过程记录

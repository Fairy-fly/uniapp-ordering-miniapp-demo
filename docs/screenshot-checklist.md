# 截图清单

建议按下面顺序截图，方便后面放进 Word 实验报告。

1. 首页：定位地址、搜索入口、banner、附近商家列表。
2. 搜索页：热门搜索、最近搜索、搜索结果。
3. 点餐页：商家信息、菜品分类、菜品列表。
4. 菜品详情：点击某个菜品弹出的详情区域。
5. 商家信息：评分、地址、电话、营业时间。
6. 地图页：模拟地图、经纬度。
7. 登录页：会员登录页面。
8. 登录成功后的个人中心：头像、昵称、手机号或登录状态。
9. 购物车：已加入菜品、数量增减、总价。
10. 提交订单页：商品列表、地址、备注、金额。
11. 支付成功页：订单号、已付款状态。
12. 已付款订单列表：我的订单页面。
13. 订单详情：商品、地址、金额、订单状态。
14. 修改个人资料：昵称、头像、性别表单。
15. 绑定手机号：手机号、验证码、绑定按钮。
16. 退款申请：订单详情里的退款申请组件。
17. git 提交记录截图：执行 `git log --oneline --decorate` 后截图。

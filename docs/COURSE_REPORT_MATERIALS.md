# 课程报告素材

本文档整理为课程报告中可使用的说明素材，风格偏课程实验记录，适合搭配运行截图使用。

## 项目名称

点餐系统小程序端

## 项目简介

本项目是《跨端应用开发》课程实验作品，使用 uni-app + Vue + Vuex 实现点餐小程序端。项目包含首页、搜索、商家信息、点餐、购物车、确认订单、支付成功、订单列表、订单详情和个人中心等页面。

项目中的商家、菜品、订单、登录、支付、验证码等数据均为 mock 演示数据，未接入真实支付、真实手机号授权和生产后端接口。

## 课程设计背景

点餐系统是移动端应用中比较常见的业务场景，适合练习跨端页面开发、组件拆分、状态管理和页面跳转。本实验重点不是接入真实支付或真实后端，而是完成一个能运行、能演示、页面完整、流程清楚的课程 Demo。

## 技术路线

本项目采用 uni-app 作为跨端开发框架，目标端为微信小程序。页面开发使用 Vue，状态管理使用 Vuex。项目通过 `pages.json` 管理页面路由，通过 `utils/request.js` 统一封装请求，通过 `utils/mock.js` 提供 mock 数据。

## 功能模块说明

### 首页模块

首页展示定位地址、搜索入口、推荐 banner 和附近商家列表。商家列表使用组件封装，便于复用和维护。首页还支持下拉刷新和上拉加载。

### 搜索模块

搜索页包含热门搜索、最近搜索和搜索结果。用户可以输入关键词，也可以点击热门关键词进行搜索。搜索结果来自 mock 数据。

### 点餐模块

点餐页包含商家信息、菜品分类、菜品列表和菜品详情。用户可以查看菜品详情，也可以直接把菜品加入购物车。

### 购物车模块

购物车支持增加数量、减少数量、清空购物车和空状态展示。购物车总数量和总价通过 Vuex getters 自动计算。

### 订单模块

订单确认页展示商品列表、配送地址、备注、商品金额、配送费和实付款。提交订单后生成 mock 订单，并模拟支付成功。

### 支付和订单列表模块

支付功能为 mock 演示。提交订单后页面跳转到支付成功页，订单会显示在已付款订单列表中。点击订单可以进入订单详情。

### 个人中心模块

个人中心展示头像、昵称、手机号和登录状态。用户可以进入资料编辑页、手机号绑定页和订单列表。登录和验证码均为 mock 演示。

## 使用到的知识点

- uni-app 跨端开发项目结构。
- Vue 页面和组件开发。
- Vuex 模块化状态管理。
- `pages.json` 页面配置和 tabBar 配置。
- 页面跳转和路由参数传递。
- 购物车数量和金额联动。
- 订单提交与订单详情展示。
- mock 数据模拟接口返回。
- HBuilderX 和微信开发者工具运行调试。

## 项目亮点

1. 页面流程完整，从首页到订单详情可以完整演示。
2. 使用 Vuex 管理购物车、订单、用户等共享状态。
3. 使用 mock 数据降低环境依赖，适合课程展示。
4. 组件拆分比较清晰，商家列表、菜品列表、购物车等模块可以复用。
5. 文档较完整，包含页面流程、mock 数据、截图清单和测试记录。

## 测试与运行记录

项目已执行结构检查和微信小程序端构建：

```bash
npm run check
npm run build:mp-weixin
```

构建产物目录为：

```text
dist/build/mp-weixin
```

可以使用微信开发者工具导入该目录进行预览。

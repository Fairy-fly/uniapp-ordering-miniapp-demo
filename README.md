# 点餐系统小程序端

本项目为《跨端应用开发》课程实验作品，使用 uni-app + Vue + Vuex 实现点餐小程序端。

项目中的商家、菜品、订单、登录、支付、验证码等数据均为 mock 演示数据，未接入真实支付、真实手机号授权和生产后端接口。

## 项目说明

本项目用于课程实验展示，重点是完成点餐小程序端的页面、交互流程、Vuex 状态管理、mock 接口封装、构建检查和实验报告素材整理。项目可以在 HBuilderX 或微信开发者工具中导入运行，适合截图和提交课程作业。

## 技术栈

- uni-app
- Vue
- Vuex
- pages.json 路由配置
- utils/request.js 统一请求封装
- utils/mock.js mock 数据

## 运行方式

安装依赖：

```bash
npm install
```

构建微信小程序端：

```bash
npm run build:mp-weixin
```

微信开发者工具导入目录：

```text
dist/build/mp-weixin
```

也可以使用 HBuilderX 直接打开项目根目录运行到微信开发者工具。

## 已完成功能

- 首页：定位、搜索入口、banner、附近商家、下拉刷新、上拉加载、分享。
- 搜索与点餐：热门搜索、最近搜索、商家搜索、菜品分类、菜品列表、菜品详情。
- 商家模块：商家信息、电话模拟、地图位置模拟。
- 会员登录：微信登录 mock、token 和用户信息保存、登录拦截。
- 购物车：加入购物车、增减数量、清空、空状态、总价统计。
- 订单管理：提交订单、配送地址、备注、金额、mock 支付成功。
- 支付与订单：已付款订单列表、订单详情、退出登录。
- 个人中心：资料修改、手机号绑定、mock 验证码、退款申请。

# 截图占位说明

本目录用于后续补充项目运行截图。建议使用微信开发者工具或 HBuilderX 运行项目后，按下面文件名保存截图，方便 README 和课程报告引用。

## 需要补充的截图

| 页面 | 建议文件名 |
| --- | --- |
| 首页 | `home.png` |
| 商家列表 | `shop-list.png` |
| 菜品详情 | `dish-detail.png` |
| 购物车 | `cart.png` |
| 确认订单 | `order-confirm.png` |
| 支付成功 | `payment-success.png` |
| 订单列表 | `order-list.png` |
| 个人中心 | `profile.png` |

## 截图建议

- 使用微信开发者工具的 iPhone 常见尺寸预览。
- 保证页面中有 mock 数据，不要截空白状态。
- 购物车截图建议先加入 2 个以上菜品。
- 确认订单截图建议保留配送地址、备注和金额区域。
- 支付成功截图建议保留订单号和已付款状态。
